# Fonte de marca (Coolvetica)

Se você tiver o arquivo da fonte Coolvetica, coloque aqui como:

- `coolvetica.woff2` (preferido)
- `coolvetica.woff`

O `@font-face` em `src/styles/theme.css` já aponta para estes caminhos. Sem os
arquivos, a marca "UPS DIGITAL" cai no fallback (Instrument Serif) sem quebrar
nada.
